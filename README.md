## Quick start (Windows)

```bat
git clone https://github.com/sellmetadone/FORMA.git
cd FORMA
install-and-run.bat
```

Or unpack **FORMA-1.0.0-source.zip**, then `install-and-run.bat`.

**Ctrl+K** — Command Palette · **Ctrl+Shift+F** — Global Search
